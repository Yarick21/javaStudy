### Что такое JDK, JRE, JVM?
1. **JDK** - Java Development Kit - это бесплатный комплект инструментов, с помощью которого создают и запускают программы при разработке приложений на языке Java.
2. **JRE** - Java Runtime Environment - это набор библиотек и интерпретатора Java-байткода, необходимый для запуска Java-приложений.
3. **JVM** - Java Virtual Machine - это среда выполнения для программ, написанных на языке программирования Java. JVM позволяет выполнять Java-программы независимо от операционной системы, на которой они были

### Объявление переменных в Java

Переменные объявляются следующим образом:
```
Тип_данных имя_переменной;
---
int a;
a = 10;

int b = 10;

var c = 1;
```
При использовании ключевого слова `var` не обязательно указывать перед именем переменной тип данных.
Объявление с помощью ключевого слова `var` можно делать только для локальных переменных, то есть внутри метода.   
Для свойств класса такой вариант объявления будет выдавать ошибку.

### Базовые типы данных в Java
1. `boolean` - хранит значение `true` или `false`
2. `byte`- хранит целое число от -128 до 127 и занимает 1 байт
3. `short` - хранит целое число от -32768 до 32767 и занимает 2 байта
4. `int` - хранит целое число от -2147483648 до 2147483647 и занимает 4 байта
5. `long` - хранит целое число от –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807 и занимает 8 байт
6. `double` - хранит число с плавающей точкой от ±4.9*10-324 до ±1.7976931348623157*10308 и занимает 8 байт
7. `float`- хранит число с плавающей точкой от -3.4*1038 до 3.4*1038 и занимает 4 байта
8. `char` - хранит одиночный символ в кодировке UTF-16 и занимает 2 байта, поэтому диапазон хранимых значений от 0 до 65535

### Логические операции сравнения

1. `|`
c=a|b; (c равно true, если либо a, либо b (либо и a, и b) равны true, иначе c будет равно false)

2. `&`
c=a&b; (c равно true, если и a, и b равны true, иначе c будет равно false)

3. `!`
c=!b; (c равно true, если b равно false, иначе c будет равно false)

4. `^`
c=a^b; (c равно true, если либо a, либо b (но не одновременно) равны true, иначе c будет равно false)

5. `||`
c=a||b; (c равно true, если либо a, либо b (либо и a, и b) равны true, иначе c будет равно false)

6. `&&`
c=a&&b; (c равно true, если и a, и b равны true, иначе c будет равно false

Здесь у нас две пары операций | и || (а также & и &&) выполняют похожие действия, однако же они не равнозначны.  
Выражение c=a|b; будет вычислять сначала оба значения - a и b и на их основе выводить результат.  
В выражении же c=a||b; вначале будет вычисляться значение a, и если оно равно true, то вычисление значения b уже смысла не имеет,  
так как у нас в любом случае уже c будет равно true. Значение b будет вычисляться только в том случае, если a равно false

### Арифметические операторы: инкремент и декремент
Инкремент и декремент бывают префиксным и постфиксным.  
1. Префиксный инкремент/декремент сначала выполняет операцию, потом присваевает значение.  
2. Постфиксный инкремент/декремент сначала присваевает значение, потом выполняет операцию. 
```
// ++ инкремент
// -- декремент

// ++a префиксный инкремент
// a++ постфиксный инкремент
// --a префиксный декремент
// a-- постфиксный декремент

int a = 0;
int b = ++a; //В этом случае к переменной 'а' сначала прибавится еденица, потом сохранится в значение.
int c = a++; //В этом случае в переменную 'с' сначала сохранится значение переменной 'а', потом прибавится еденица.
```

### Логические конструкции  
[Подробнее тут](https://metanit.com/java/tutorial/2.5.php) или [тут](https://javarush.com/groups/posts/cikly-java)  
В языке Java используются следующие условные конструкции: `if..else` и `switch..case`
#### Конструкция `if() {} else {}`
```
    int a = <значение>;
    int b = <значение >;
    if (a < b) {
       System.out.println("a меньше b");
    } else if (a = b) {
       System.out.println("a равно b");
    } else {
       System.out.println("a больше b");
    }
```
#### Конструкция `switch() {case ->}`
```
    int result = switch (day) {
    case MONDAY -> {
        System.out.println("First day");
        yield 1;
    }
    case TUESDAY -> {
        System.out.println("Second day");
        yield 2;
    }
    default -> {
        System.out.println("Other day");
        yield 0;
    }
};
```
* yield - ключевое слово, которое используется для возврата значения из блока switch.  
* Оператор `default` необходим, чтобы указать действие по умолчанию, если не попали ни в один из кейсов.

### Параметры переменной длины
Если в метод/функцию необходимо передать N-количество параметров одного типа, можно использовать  следующую конструкцию `String method(String ...nums);`  
Аналогично для примитивных типов данных: `int method(int ...nums);`  
Пример:
```
public class Program{
      
    public static void main (String args[]){
          
        sum(1, 2, 3);           // 6
        sum(1, 2, 3, 4, 5);     // 15
        sum();                  // 0
    }
    static void sum(int ...nums){
         
        int result =0;
        for(int n: nums)
            result += n;
        System.out.println(result);
    }
}
```
### Модификаторы
#### Модификаторы видимости
Для того, чтобы наш класс был доступен с любого пакета в проекте, у него устанавливается модификатор `public`:
```
public class Simple {

}
```
Если мы хотим, чтобы наш класс был доступен только в том пакете, в котором мы пишем код, 
то мы не указываем модификатор перед объявлением класса.   
Такой принцип ещё называют - инкапсуляция:
```
class Simple {
    ...
}
```
#### Модификатор `static`
Данный модификатор позволяет обращаться к свойствам и методам класса, как к статичиским объектам, то есть не создавая 
экземпляр данного класса для обращения к ним.  
Модификатор `static` позволяет разграничивать обьектный и процедурный стиль.

#### Модификатор `final`
Если необходимо объявить константу используется ключевое слово `final`:
```
public static void declareParam() {
    final int VALUE_PARAM = 10;
    final var VALUE_PARAM2 = 11;
}
```

### Обработка исключений

#### Блок `try{} catch()`
Для обработки внештатных ситуаций в java используется конструкция `try{} catch()`:
```
public static void declareParam() {
   try {
   ....
   } catch (Exception e) {
   ...
}
```

#### multi catch
В блоке catch() можно обрабатывать не только одно исключение, но и несколько, используя логическое или `||`:
```
public static void declareParam() {
   try {
   ....
   } catch (Exception e || Exception2 e2) {
   ...
}
```
Блок catch содержит в себе один из классов исключений, которые мы хотим обработать.
Есть базовый класс исключений `Throwable`, от которого наследуются все остальные классы исключений.

Есть два фундаментальных класса наследника от `Throwable`: `Exception` и `Error` 
- Error - эти ошибки не обрабатываются программистом, а обрабатываются операционной системой.
- Exception - это ошибки, которые можно обработать программистом блоком `try{} catch()`.

#### Проверяемые(Checked) и непроверяемые(Unchecked) исключения
- `runtime` - непроверяемые исключения, которые не требуют обработки в блоке `try{} catch()`
- `exception` - проверяемые исключения, которые требуют обработки в блоке `try{} catch()` и для вызывающей стороны должен быть указан `throws`

В этом примере `declareParam()` - метод, внутри которого выбрасывается исключение. 
Любой другой метод, который будет вызывать `declareParam()` должен обязательно обработать исключение в конструкции `try{} catch()` или указать для себя через `throws`, что он может выбросить исключение.
```
public static void declareParam() throws Exception {
   if (<условие>) throw new Exception("<текст>");
}
```

### Блок `try() {}`
Конструкция используется `try() {}` для автоматического закрытия ресурсов, её ещё называют `try-with-resources`.
```
public static void initConnection() {
    Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/test", "root", "root");
    try(connection) {
        ...
        // В конце блока try неявно вызовется connection.close() 
    }
}
```
пример кода без конструкции
```
public static void initConnection() {
    Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/test", "root", "root");
    ...
    connection.close() // В конце метода необходимо явно закрывать соединение 
}
```

### Array, Collections

Многие коллекции в java - реализации интерфейса `Collection`, который в свою очередь реализует интерфейс `Iterable`.

Основые коллекции, реализующие `Collection`:
- `List` - Изменяемое множество, которое хранит в себе элементы в порядке их добавления, элементы могут повторяться.
  - Классы `ArrayList`, `LinkedList` основные классы, реализиющие интерфейс `List`.
- `Set`- Изменяемое множество, которое хранит в себе неповторяющиеся элементы без определенного порядка.
  - Классы `HashSet`, `TreeSet` основные классы, реализиющие интерфейс `Set`.

Коллекция `Map` - Множество, которое хранит элементы в виде пары ключ:значение. Не реализует интерфейс `Collection`, но имеет схожие методы.
Основые классы, реализующие `Map`:
- `HashMap`
- `TreeMap`

### Lambdas
Синтаксис - `() -> {}`, фигурные скобки можно опускать, если тело состоит из одной строки. 
```
@FunctionalInterface
public interface Predicate<T> {
    boolean test(T t);
}
public static void main(String[] args) {
    var str = "123";
    Predicate<String> pr = s -> s.length() > 3; // реализуем метод test из интерфейса Predicate
    Boolean result = pr.test(str) // вызываем метод test() из объекта pr, который реализовал  метод интерфейса Predicate
    System.out.println(pr.test(str)); // вывод: False
}
```
В java есть интерфейсы, которые содержат только один абстрактный метод. Такие интерфейсы называются функциональными интерфейсами.
```
@FunctionalInterface
interface Sum {
    int sum(int a, int b);  
    void foo(); // Ошибка, так как функциональный интерфейс может содержать только один абстрактный метод!
}
```
Анотация `@FunctionalInterface` указывает, что интерфейс является функциональным и добавляет валидацию на этапе компиляции интерфейса.   
Однако, она необязательна, но если мы захотим добавить второй метод в этот интерфейс, то мы получим ошибку в коде, где будем пробовать реализовывать методы этого интерфейса через лямбду.
```
public static void main(String[]) {
    var result = (a,b) -> a + b; // Реализация функционального интерфейса через лямбда выражение
    var result = a -> a + ""; // Если у нас есть только один параметр, то мы можем не указывать круглые скобки
    return result;
}
```

### Stream API
В java для работы с коллекциями существует класс `Stream`.  
Он позволяет выполнять различные операции над коллекциями, такие как фильтрация, сортировка, группировка, подсчет и т.д.   
Методы класса `Stream` реализуются при помощи функциональных интерфейсов.
```
public static void main(String[] args) {
        Collection<Integer> coll = List.of(1, 2, 3, 4, 5);
        var res = coll
                .stream() // Создаем поток
                .filter(element -> element < 5) // Фильтруем элементы внутри потока
                .collect(Collectors.toList()); // Собираем элементы в список.
        
        System.out.println(res); // Выводит: [1, 2, 3, 4]. 
        // Без метода collect(Collectors.toList()) наш вывод был бы пустым - это терминальный метод для потока.
    }
```
Важно знать терминальные методы для объектов типа `Stream`. Это такие методы, которые завершают фактические действие/действия над потоком:
- `reduce()`
- `forEach()`
- `collect()`
Если объект типа `Stream` не содержит терминального метода, то никакие действия над потоком не будут выполнены.
