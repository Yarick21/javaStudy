### Docker hub
1. В [Docker hub](https://hub.docker.com/) можно найти большинство образов приложений, необходимых для разработки.
2. `alpine` - легковесный образ, в котором уже есть пакетные менеджеры, его удобно использовать как базывый образ в Dockerfile.

### Команды Docker
- `docker run` - Выполняет сразу `pull` образа, `create` контейнера и `start` запуск, если образа ещё нет.
- `docker pull <image:version>` - Скачивает образ из Docker hub, если не ещё скачан
  - Пример `docker pull postgres:14.18-bookworm`
- `docker ps` - Выводит список запущенных контейнеров
- `docker rm` - Удаляет контейнер
- `docker stop` - Останавливает контейнер
- `docker images` - Выводит список скачанных образов
- `docker push` - Загружает образ на Docker hub
- `docker build` - Создаёт образ из Dockerfile
- `docker logs` - Выводит логи контейнера

### Dockerfile
Дериктивы Dockerfile:
- `FROM` - базовый образ
- `RUN` - выполняет команду в контейнере во время сборки образа 
- `WORKDIR` - устанавливает рабочую директорию в контейнере
- `COPY` - копирует файлы и каталоги из локальной файловой системы хоста в файловую систему образа Docker во время сборки
- `EXPOSE`- указывает, какие порты будут открыты в контейнере.
  - Директива носит только информационный характер, и не открывает порты на хосте.
  - Для открытия (проброса) портов на хосте используется флаг `-p` при запуске контейнера `docker run -p 8080:80 my-image`
- `ENTRYPOINT` - задаёт команду по умолчанию, которая будет выполняться при запуске контейнера на основе образа.
- `CMD` - задаёт параметры по умолчанию, которые будет выполняться при запуске контейнера на основе образа. Если `ENTRYPOINT` указан, то `CMD` будет добавлен к `ENTRYPOINT` как аргумент.
