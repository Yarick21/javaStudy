# Spring https://spring.io/

## Настройка Spring context
Настроить спринг контекст можно двумя способами
- С помощью xml файла, добавив туда тэги Spring (Этот способ устарел, в 12 factor app не используется)
- С помощью xml файла + аннотации в коде (Также устаревший способ)
- С помощью аннотаций в коде (Актуальный способ, используется в современных 12 factor app)

## Spring container
**Spring container** - это контейнер, в котором хранятся объекты, которые мы можем использовать в нашем приложении.  
Основные функции Spring container:
- IoC
- DI

## IoC - Inversion of Control
**IoC** - Inversion of Control - инверсия управления. Это означает, что мы не создаем объекты сами, а Spring container создает их за нас и управляет ими. 
Например, мы в Java коде описали класс, при помощи IoC Spring самостоятельно создает объект этого класса и нам не придется вручную (Creator) создавать его.

## Spring Bean
**Bean** - одна из основных состовляющих IoC, это объект, которые создается и управляется Spring контейнером. Мы также можем его использовать в нашем приложении.

## DI - Dependency Injection
Dependency injection - внедрение зависимостей - эта функция позволяет автоматически внедрять зависимости в наши Java объекты при их создании.  
Основные способы внедрения зависимостей:
- Через конструктор
- Через setter
- Autowiring (@Autowired)

## Bean Scopes
- **Singleton** - stateless подход, когда создается один Bean на весь жизненный цикл программы, который не хранит состояние.
  Например, создаем `class Foo`и от этого класса можно создать только ОДИН объект в Spring container. То есть, если мы захотим создать несколько java объектов Foo через new Foo() и вызвать setter класса, то этот setter отработает для всех созданных объектов. 
- **Prototype** - stateful подход, когда создается новый Bean в Spring container на каждый запрос. Например, создаем `class Foo`и от этого класса можно создать несколько java объектов, которые будут хранить в себе то состояние, которое мы настроем через DI.
- **Request**
- **Session**
- **Application**
- **WebSocket**
- **GlobalSession**

## Аннотации Spring и не только
- @Scope - указывает на scope бина
- @Autowired - используется для автоматической инъекции (DI) бинов
- @Component - используется спрингом для обнаружение классов, которые будут созданы как бины в спринг контейнере.
- @Value - с помощью этой аннотации можно инициализировать переменные. Прям в коде или через файл .properties
- @PropertySource - используя эту аннотацию можно указать файл .properties, из которого будут тянуться значения для переменных, с аннотацией @Value
- @PostConstruct (из jakarta.annotation) - используется в спринге на методе для выполнения логики после создания бина
- @PreDestroy (из jakarta.annotation) - используется в спринге на функции/методе для выполнения логики перед удалением бина
- @Configuration - испольузуется в спринге для обозначения класса, возвращающего бины в через функции. То есть внутри класса есть функция с аннотацией @Bean, которая возвращает объект. Его спринг регистрирует как бин в спринг контейнере.
- @ComponentScan - используется в спринге для сканирования пакетов и поиска классов, которые будут созданы как бины в спринг контейнере.
- @Bean - используется в спринге для обозначения функции, возвращающей обьект, который спринг зарегестрирует как бин в контейнере.
- @Qualifier - используется для упорядочивания бинов с одинаковым названием
